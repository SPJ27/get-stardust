# Get Stardust (for hackclubbers only)

This is a prank website built to troll Hack Clubbers who try to scam hc. When someone fills out the form believing they'll get free Stardusts, they instead get publicly "banned" in a Slack channel -  but as a joke ofc.

Also, this is obviously meant to be a joke, so fraud department, please don't ban me. I let the person know that this is a joke.

## What it does

1. The user fills out a form with their Slack ID, Stardance ID, and how many Stardusts they want to steal
2. The server invites them to a dedicated Slack channel (if they aren't already in it)
3. A bot posts a fake permanent ban message tagging them in the channel

## Tech stack

- SvelteKit
- Tailwind CSS
- Slack Web API

This is a very simple website, that just uses slack api without any real significance.
